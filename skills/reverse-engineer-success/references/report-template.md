# Report template

Use these sections, in this order, in the Markdown report. The shareable page has sections 1–8 in the same order. Delete this instruction block and all guidance text from the finished report.

```markdown
# <Subject>: blueprint

**Researched:** YYYY-MM-DD
**Prepared for:** <the reader's goal and situation, or "general reader">
**Sources:** <what was reachable, and any major source that wasn't>

## 1. What the business really is

<Two to four sentences on what makes the money, how customers are found, and how the headline claim fits in. Then say how far the evidence supports it, in one sentence.>

## 2. Step-by-step blueprint

<A numbered sequence someone could follow. Mark each step's evidence label. Include tools and specifics where known.>
```

## Writing guidance

- Lead each section with the finding.
- State facts, not impressions. "34 subscribers from about 4,000 new users" beats "weak conversion".
- Put the label beside the number it describes.
- Keep the reader's situation in section 6. The earlier sections describe the subject, whoever is reading.
- Link to the most specific source available.
